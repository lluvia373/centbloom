# Stockfolio

나의 투자를, 나답게. 주식·ETF 자산, 투자성과, 관심종목과 투자 생각을 연결하는 개인 투자 워크스페이스입니다.

## 로컬 실행

```sh
npm ci
npm run dev -- --hostname 127.0.0.1 --port 3000
```

http://localhost:3000 에서 열 수 있습니다. Next.js 16.2.10, React 19, TypeScript, Tailwind CSS 4를 사용합니다.

## 새롭게 구성한 화면

- **대시보드**: 총 투자자산, 누적 평가손익, 전일 종가 대비 주가 변화, 기간별 자산 차트, 시장·종목별 자산 배분
- **내 포트폴리오**: 국내·해외 필터, 보유종목 검색·정렬, 실제 거래 수정·삭제·8초 되돌리기, 보유 자산 CSV
- **성과 분석**: 운용수익률, 종목별 손익 기여, 주가·환율 영향 분리, 실제 포트폴리오의 기간별 분석과 벤치마크 검색
- **관심종목**: 실제 종목 검색, 시세 확인, 목표 매수가 저장·수정, 현재가와 목표가 차이
- **투자 노트**: 작성·수정·삭제 확인, 종목/본문 검색, 관찰·매수 검토·복기 필터, 정렬
- **설정**: KRW/USD, 샘플 화면 전환, 거래 JSON 백업·검증·병합/교체 복구

기존 `/community` 주소는 개인 투자 노트 `/journal`로 연결됩니다. 실시간 커뮤니티나 푸시 알림 서비스는 제공하지 않습니다.

## 샘플과 실제 데이터

거래가 없는 첫 방문에는 **샘플 포트폴리오**를 보여줍니다. 화면 상단에 예시임을 표시하며 샘플 시세와 차트는 실제 시장 데이터가 아닙니다. 샘플은 실제 거래 저장소에 삽입되지 않습니다.

`내 포트폴리오 시작하기`를 누르거나 거래를 기록하면 실제 기록을 볼 수 있습니다. 설정에서 샘플로 다시 전환할 수 있습니다. 종목 상세와 거래 입력은 항상 실제 시세를 조회합니다.

거래와 표시 통화는 기존 저장 구조를 유지합니다. Supabase를 연결하면 로그인 계정별 기존 서버 동기화 기능을 사용하며, 미설정 상태에서는 브라우저에 저장합니다. 관심종목과 투자 노트는 **계정별로 분리된 현재 브라우저의 로컬 저장소**에만 보관됩니다. 거래 JSON 백업은 관심종목/노트를 포함하지 않습니다.

Google 로그인을 연결하려면 `.env.example`을 참고하여 `.env.local`에 기존 프로젝트의 공개 URL과 publishable key를 설정하세요. Supabase Auth의 Google 제공자와 localhost 리디렉션 허용도 필요합니다. 저장소에는 비밀 키를 포함하지 않습니다.

## 계산 범위

- 총 투자자산은 보유 주식·ETF 평가액입니다. 현금 잔액과 배당 현금 기록은 포함하지 않습니다.
- 평가손익은 현재 평가액과 매입 당시 환율을 반영한 원가의 차이입니다.
- 주가·환율 기여도와 운용수익률은 원화 기준입니다.
- 자산 차트의 USD 표시는 원화 일별 기록을 현재 환율로 환산한 참고 금액입니다.
- '오늘의 주가 변동'은 각 종목의 최근 거래일 전일 종가 대비 변화에 현재 보유 수량과 환율을 적용합니다. 당일 환율 변동은 제외합니다.
- 목표 매수가는 화면에서 확인하며, 백그라운드 감시나 푸시 알림을 전송하지 않습니다.

## 검증

```sh
npm run lint
npm run build
```

개발 시 체크리스트와 현재 작업 상태는 `PROJECT_STATUS.md`에 기록합니다. 시세 공급은 현재 개발용 `yahoo-finance2`이며 상용 출시 전 데이터 표시 권한을 확보한 공급자로 전환해야 합니다.
